# 奶龙空洞骑士皮肤

本目录可直接作为 CustomKnight 皮肤目录使用。它包含 `Default` 的完整资源树；未被参考图覆盖的资源保持原版，避免缺文件或误改其他角色。

本次按用户提供的奶龙动作参考图重建了玩家相关帧，并以 `Default` 母版保留原始画布尺寸、透明通道、图集位置和动作方向：

- `Knight.png`
- `Sprint.png`
- `DreamArrival.png`
- `Wings.png`
- `Webbed.png`
- `Birthplace.png`
- `Shriek.png`
- `Dreamnail.png`
- `Cloak.png`

根据展示视频又校正了 `Knight.png`：修复了待机误用竖直上挑帧、空中/普通攻击时闪回原版小骑士的问题；本次定点修复了 77 个残留角色图块，并重新指定了 12 个待机/空中图块。斩击和其他特效保持原图集效果。

HUD、NPC、护符、背包、法术、货币、灵魂槽、宠物和场景资源均为 `Default` 原文件的完整副本。
